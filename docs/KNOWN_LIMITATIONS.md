# 当前限制

以实际运行记录为准；交接文档的目标不是通过声明。

## 平台与分发

- 当前验证主机为 macOS Apple Silicon。macOS Intel、Windows x64未构建或运行验证；现有Parallels为Windows ARM64，不替代目标平台。
- 尚无签名、公证、安装包或自动更新交付。源码构建需要Rust及完整Xcode/Metal工具链。
- NSH保留独立实验，不进入默认编辑器；真实IME、完整焦点/DPI/主题同步、正式SDK与插件生命周期门槛未通过。JSON扩展、LSP、图片查看器、离线扩展包尚未实现。

## 文件与预算

- 默认普通可编辑文件上限64 MiB；超过阈值以及超长行等输入走只读分页。不是任意大文件编辑器；大文件原位替换与写回不提供。
- 普通编辑器合计内容准入256 MiB、最多128个已hydrate实体；仅未修改且无撤销历史的文件标签可被回收。内容预算不是RSS硬上限，撤销与排版缓存额外占用。
- UTF-8、UTF-8 BOM、统一LF/CRLF为本轮保真范围；混合换行、二进制或不支持编码不按可编辑文本静默改写。
- 分页视口64 KiB、共享页缓存64 MiB、共享稀疏索引预算16 MiB。长行分段显示，不先整行shaping；稀疏索引未覆盖处行号可能未知。
- 普通正则/大小写折叠搜索限16 MiB；结果上限10,000，达到上限明确标记截断。分页仅支持流式字面量，不支持任意跨文件正则。
- 原子多编辑：同内容多位置走原生多光标；不同替换内容的跨度与输出受4 MiB预算约束，超限拒绝且不部分修改。

## 日常编辑界面

- 侧栏目前管理打开文档和最近文件，不是项目目录树；跨目录搜索未实现。
- 自定义复制/删除/移动/注释只操作活动选区，会收拢其他光标；上游完整选区集合未公开。不将这些命令宣传为多光标批量编辑。
- 行命令最多50,000行、4 MiB跨度/输出；只提供已知`//`、`#`、`--`行注释，不为JSON等格式插入非法注释。
- 视图偏好写入独立于草稿恢复。已有偏好flush尚未结束时的后续写入错误，可能到下一次flush或退出才显示；错误保持可见于持久化屏障，不影响正文恢复确认。
- 本轮后半段macOS锁屏阻止外部键鼠事件及可靠窗口截图。真实AppKit窗口内的程序化原生smoke与GPUI键盘派发验证，不能替代解锁后的鼠标操作、系统Option键输入及真实IME验收。

## 恢复与保存

- SQLite草稿恢复不等于用户文件已保存；恢复确认不能清除dirty。
- 单草稿超过64 MiB后恢复保护降级，需显式另存抢救；退出必须提示，不能宣称新修改已自动保护。
- 损坏单条元数据不阻断其他草稿；损坏条目的原始数据保留且有warning，但正常hydration不提供其抢救导出。
- 清单上限1024标签；超过满清单的额外无布局恢复头可能不显示。本轮UI已hydrate实体上限更低。
- macOS安全保存拒绝硬链接目标，解析符号链接；保留元数据并明确区分已发布与完全同步结果。外部写入的检查和rename之间仍存在竞争窗口，不提供抵御恶意保持元数据不变写入的强快照保证。
- 进程故障注入、事务测试及F_FULLFSYNC不等于真实断电验证；没有断电实验结论。

## 测量边界

- 数据位于外置USB SSD，不是内置NVMe；未清除OS缓存，均标为warm/unspecified。服务读取延迟不是GUI首屏，输入提交耗时不是屏幕端到端延迟。
- 64 GiB完整文件扫描、16文件共享缓存、100草稿惰性恢复已有服务层证据；原生主应用的最终运行状态见测试报告，不从服务测试外推。
- Unicode键盘事件注入不替代真实中文输入法预编辑、候选窗口及组合提交验收。
